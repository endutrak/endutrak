El panel guarda los cambios directamente en tu repositorio de GitHub. Solo se configura una vez en cada navegador.

¿Cómo creo el token?
  1. Ve a GitHub → Fine-grained tokens.
  2. Repository access: Only select repositories → tu repo de endutrak.
  3. Permissions: Contents: Read and write y Actions: Read and write.
  4. Copia el token y pégalo aquí. Se guarda solo en este navegador.
